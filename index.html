About NixOS-for-TV

It is the sole project where TVs and NixOS comes first. Tested always on QEMU and not actual hardware.

To turn your NixOS machine to a Plasma Bigscreen interface, you can download the configuration and packages from where it says Configuration and where it says Packages.

This project was built with KDE Software, such as Plasma Bigscreen. The strangest remote you can use happened to be a PlayStation 4 controller because hid-playstation existed in the kernel since Linux 6.2.
